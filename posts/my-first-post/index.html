文章内容 Link to heading

在这里，我将分享一些关于使用Hugo建站的经验。

为什么选择Hugo？ Link to heading

  1. 速度快 - Hugo是世界上最快的静态网站生成器
  2. 简单易用 - 使用Markdown编写内容
  3. 主题丰富 - 有很多漂亮的主题可以选择

如何开始？ Link to heading

首先，你需要安装Hugo，然后选择一个主题，比如我们现在使用的Coder主题。

hugo new site my-blog
cd my-blog
git submodule add https://github.com/luizdepra/hugo-coder.git themes/hugo-coder

总结 Link to heading

Hugo是一个非常棒的静态网站生成器，希望这篇文章对你有帮助！
